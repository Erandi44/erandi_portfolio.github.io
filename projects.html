AI-Driven Alzheimer’s Drug Discovery Pipeline

This project implements an end-to-end computational pipeline for Alzheimer's disease drug discovery integrating QSAR modeling, machine learning, deep learning, and generative AI. Bioactivity data for multiple AD-related targets were collected from ChEMBL and processed through data cleaning, descriptor calculation, and feature selection. Traditional ML models and Chemprop deep learning models were developed using nested cross-validation and Bayesian optimization. An ensemble QSAR model was constructed and used to guide generative molecule design using the REINVENT framework. Generated molecules were further filtered using medicinal chemistry rules, structural alerts, and ADMET/toxicity screening to identify promising candidate compounds.

BACE1 Inhibitor Prediction Using Traditional ML Methods and Deep Neural Networks

This project focuses on predicting the pIC50 values for beta-secretase 1 (BACE1) inhibitors, an important target for Alzheimer's disease drug discovery. Molecules with reported IC50 values were sourced from the ChEMBL database, followed by Exploratory Data Analysis (EDA). Various machine learning (ML) models, including traditional regression techniques and deep neural networks, such as Graph Neural Networks (GNN), were developed to predict pIC50. Additionally, a Graphical User Interface (GUI) was built to allow users to input SMILES and receive predicted pIC50 values.

BRICS-Based Molecular Fragmentation for Scaffold Analysis

This project processes 100,000 bioactive molecules from the ChEMBL database using the BRICS (Breaking of Retrosynthetically Interesting Chemical Substructures) algorithm to generate chemically meaningful fragments. The fragments were then clustered based on structural similarity using both k-means and the Butina algorithm. Tanimoto similarity scores were calculated between each fragment and its respective cluster center to evaluate intra-cluster similarity. This pipeline facilitates scaffold analysis, diversity profiling, and supports fragment-based library design and generative modeling applications.
